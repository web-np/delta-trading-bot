# Delta Live WebUI Trading Bot

Live Python WebUI Trading Application with real-time candles, multi-indicator support, dynamic indicator additions/removals, and automated trading toggles for Delta Exchange.

## Features
- **Delta API Integration**: Direct wallet balance display & trade signals.
- **1-Second Live Updates**: Real-time candle charts.
- **Dynamic Indicators**: Add, customize color/period, and delete EMA, SMA, and RSI.
- **Auto-Trading On/Off Toggle**: Built-in signal detection.

## Deploying to Streamlit Cloud (Free Live Hosting)
1. Fork or push this repository to GitHub.
2. Go to [share.streamlit.io](https://share.streamlit.io/).
3. Connect your GitHub account and select this repository.
4. Set Main file path as `app.py`.
5. Click **Deploy!**
